# 21 Cross-Lingual Prompt Steerability

Zhang, Zhou, Ergen, Logeswaran, Lee & Jurgens（伊利諾大學、密西根大學、LG AI Research）· arXiv 2025 · [arXiv 2512.02841](https://arxiv.org/abs/2512.02841) · 本機檔案 `21_CrossLingualPromptSteerability_2025.pdf`

## 一句話重點

研究「同一份 system prompt 放到不同語言的任務上，效果穩不穩定」。發現 system prompt 和題目同一種語言時略好；而**「角色」、「行為」、「風格」這類 prompt 成分會讓模型注重符合角色、勝過完成任務，導致跨語言的準確度與一致性下降**。

## 它在問什麼

1. 什麼樣的 system prompt 能讓模型在多種語言上都表現好又穩定？
2. 能不能自動找到這種 prompt？
3. 好的 prompt 怎麼改變模型的推理方式？

## 怎麼做

- **四個指標**：跨語言平均準確度、準確度的跨語言變異、同一題在不同語言答案是否相同（一致性）、輸出長度的跨語言變異。
- **10,000 個 prompt 成分，分成 10 類**：好特質（「你很聰明可靠」）、**角色**、風格、情緒、**情境**、越獄、**行為**、思維鏈、安全、跨語言指示。隨機組合成 1,000 個 prompt，再用迴歸分析每一類成分的效果。
- **比較 system prompt 用英文 vs. 跟題目同一種語言。**
- 5 種語言（英、中、西、法、印地）；3 個約 8B 的開源模型（Gemma-3-12B、Llama-3.1-8B、Qwen2.5-7B）；3 個資料集（MMLU-Pro、MATH500、道德判斷 UniMoral）。

## 發現了什麼

- **system prompt 和題目同語言時略好**，但差距很小；英文 system prompt 會讓跨語言變異顯著變大。
- **思維鏈、情緒、情境**成分：準確度與一致性提高、跨語言差異變小。
- **角色、行為、風格**成分：準確度與一致性下降。作者看輸出後發現，這些成分「有時讓模型優先符合風格，而不是任務相關性」，推理變得不自然或離題。
- 自動 prompt 優化可以讓四個指標都改善 5–10%；好的 prompt 讓推理更有結構、更少中途切換語言。

## 跟我們的關係

**「角色成分會讓模型注重符合角色、勝過完成任務」是我們要記錄的副作用。** 精讀 13 觀察到 persona 會讓 agent 先聊天再行動；這篇也發現角色與行為描述會讓推理離題。對我們來說，**這其實是我們「想要」的效果**（害羞 persona 就是要讓 agent 不做最有效率的事，也就是不求助），但必須和「persona 讓模型變笨」分開（精讀 14 的副作用）。所以記錄正確率仍然重要。

**system prompt 語言與任務語言的 2 × 2 已經有人看過，但看的是準確度。** 我們的 persona 語言 × 任務語言設計，量的是行為，可以引用這篇作為「語言搭配會影響效果」的前例；它的結論是同語言略好，但差異很小。

**可以借用的方法：**

- **把 prompt 拆成成分做迴歸**：我們的 persona 也可以拆成成分（有沒有 if–then、有沒有情緒詞、有沒有規範描述），用迴歸看每個成分對求助率的貢獻。這比只比較幾個固定層次更有統計效率，也更能回答「哪一種描述最有效」。
- **「情境」與「情緒」成分有正面效果**：我們的 persona 如果加入情境（在全班面前）和情緒（會緊張、怕丟臉），可能比純特質更有效，可以當成假設。

**要區隔的地方：** 目標是「讓模型在各語言都表現好」，不是「讓 persona 控制行為」；模型都是 8B 左右的小模型；中文是簡體。
