# 22 Diagnosing Korean-Language LLM Political Bias via Census-Grounded Agent Simulation

Sungwoo Kang（高麗大學，單一作者）· arXiv 2026 · [arXiv 2605.18395](https://arxiv.org/abs/2605.18395) · 本機檔案 `22_KoreanCensusGroundedPolitical_2026.pdf`

## 一句話重點

用韓文、依韓國人口普查建立 5,000 個選民 agent 模擬韓國選舉：**沒有特別處理時，「中間派」agent 有 97% 投給進步派**；需要明確的政黨線索、平衡的中間派描述，加上「請以這位選民、而不是 AI 的角度思考」，才能降到 59%。

## 它在問什麼

英文 LLM 的政治偏左，在非英語（韓文）的選舉模擬中也會出現嗎？模擬失準的具體機制是什麼？

## 怎麼做

四個步驟建立 agent：

1. **人口普查抽樣**：從韓國 2020 年普查微觀資料，依年齡、性別、地區、教育、婚姻狀況抽出 agent。
2. **賦予政治傾向**：依韓國綜合社會調查，給每個 agent「進步／中間／保守」的傾向與信念數值（政府責任、經濟觀、社會觀、民族自豪感等）。
3. **依 Gallup 校正**：讓中間派比例接近真實的 48%。
4. **模擬投票**：每個 agent 讀選舉情境，以 JSON 輸出候選人、理由、信心。

模型：Qwen3-30B、EXAONE-4.0-32B（韓國 LG 的模型）、Llama-3.1-8B、DeepSeek-R1-8B；六次韓國選舉（2017–2025）。

## 發現了什麼

- **中間派被拉向進步派**：原始 prompt 時 97% 投進步派；只給人口特徵時 82%；加上緩解措施後 59%。
- **緩解措施有三個**：system prompt 中明確寫出政黨與意識形態的對應、描述中間派時強調「兩邊投票機率相同」、**指示「不要從 AI 的角度」思考**。
- **「說到」不等於「投給」**：Qwen3 在推理中提到第三黨候選人的比例是 10.6%，但真的投給他的只有 7.4%；EXAONE 則幾乎不提（0.7%）。作者把它拆成「沒想到」和「想到了但不選」兩種失敗。
- **情境描述比世界知識更有力**：只改寫選舉情境的描述，就把一位候選人的預測得票率從 0.9% 拉到 18.8%。
- **不同模型偏差方向相反**：同一次選舉，Qwen3 偏進步 11.8 個百分點，EXAONE 偏保守 17.2 個百分點。

## 跟我們的關係

**這是老師「投票 tool」例子最直接的前作，而且是非英語。** 它證明了：在投票這個行為上，**模型的預設政治偏向非常強，persona 要花很大力氣才能抵消**。如果做政治情境，模型的預設偏向可能會淹沒 persona 顆粒度的效果，這也是我們選擇以教育為主場景的理由之一。

**「不要從 AI 的角度思考」是一個值得測試的因子。** 它和精讀 06 的「機械式套用規則」、精讀 13 的「規則型角色 prompt」是同一類：**在 persona 之外再加上一句「請完全照角色行動」的指令**。可以考慮把「有無這句強化指令」當成一個實驗因子。

**「推理中提到」vs.「實際行動」的拆解可以直接借用：** 把我們的五步驟指標中的「察覺」（推理中提到「不會」）和「決定」（真的呼叫求助 tool）分開算，就是這篇的「沒想到」vs.「想到了但不選」。

**可以借用的方法：**

- **用真實統計資料決定 persona 分布**：如果之後做大規模模擬，可以用台灣的教育統計（例如 PISA、TIMSS 中台灣學生的求助或數學焦慮資料）決定 persona 的比例。
- **跨模型比較偏差方向**：不同模型的預設可能相反，所以要報告每個模型各自的結果，不能只報平均。

**要注意的地方：** 單一作者、未經同行審查；主要用 Qwen3；做的是選舉預測，不是 persona 控制力研究。
